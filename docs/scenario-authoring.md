# Scenario作成ガイド

XStoryBotの物語(Scenario)をGoogle Sheetsで書きはじめるための入門ガイドです。読者として、Sheetsを編集するシナリオ作成者を想定しています。Botの設定やデプロイはBot管理者の作業なので、このガイドでは末尾の[Bot管理者向けメモ](#bot管理者向けメモ)にまとめました。

全機能のリファレンスではありません。ここでは、物語の主要な導線を安全に作って更新できるところまでを扱います。現行の標準形式(version 3)を前提にしています。

## 用語

| 用語 | 意味 |
|---|---|
| scene | 物語の「場面」。利用者は常にどれか1つのsceneにいます。`*名前`で始めます |
| label | scene内の「途中の目印」。`#名前`で書きます |
| 条件 | A列に書く、利用者の入力に反応するためのきっかけ |
| message | 利用者に表示する文章やメディア |
| command | `@`または`/`で始まる命令。表示以外の動作(分岐、記憶など)もできます |
| action | ボタンなどを押したときに内部的に送られる合図。利用者が入力するテキストとは別物です |
| build | Sheetsの内容をBotに反映する変換処理。管理画面から実行します |

## Spreadsheetの構成

1つのSpreadsheetに複数のSheetを作れます。読み込まれるのはA列〜Z列だけです(それより右の列はメモに使えます)。

Sheet名には次の規則があります。

| Sheet名 | 扱い |
|---|---|
| 通常の名前(例: `story`) | 物語のSheet。Sheet名はsceneの住所の一部になります(例: `story/森`) |
| `_`で始まる(例: `_メモ`) | 読み込まれません。下書きや長いメモはここへ |
| `$`で始まる(例: `$定数`) | 定数Sheet(後述) |
| `名前.環境名`(例: `story.prod`) | その環境でだけ読み込まれます。Scenario上のSheet名は`story`になります。環境名はBot管理者に確認してください |

## 行の書き方

基本形は「A列の条件に入力が一致したら、B列以降を上から順に実行する」です。

| A列: 条件 | B列: message／command | C列以降: 引数 |
|---|---|---|
| `こんにちは` | `こんにちは！` | |
| `画像` | `@image` | 画像のURL |

- **A列が空の行**は、直前の条件の続きです。1つの入力に対して複数のmessageを順に返せます。
- **行頭の空セル**は階層(インデント)を表します。Buttonの選択肢のように「親の行にぶら下がる行」は、親のcommandより1つ右の列から書きます(次の例の4〜5行目)。
- セルに`#`または`;`の**1文字だけ**を書いた行と、空行は無視されます。`; メモ`のように文字を続けると条件として解釈されてしまうので、文章のメモは`_`Sheetに書いてください。

## 最小のScenario

開始メッセージ、通常の応答、Button、scene移動を含む最小の例です。

| 行 | A | B | C | D |
|---|---|---|---|---|
| 1 | `##line.follow` | `ようこそ！` | | |
| 2 | `こんにちは` | `こんにちは。` | | |
| 3 | `選ぶ` | `@button` | `行き先を選んでください` | |
| 4 | | | `森へ` | `*森` |
| 5 | | | `街へ` | `*街` |
| 6 | `*森` | `森に着きました。` | | |
| 7 | `戻る` | `*街` | | |
| 8 | `*街` | `街に着きました。` | | |

読み解き方:

- 1〜5行目はまだ`*名前`が出てきていない、**Sheet先頭の名前なしscene**です。最初のSheetのこの部分が物語の開始地点になります。さらに、**ここに書いた条件はどのsceneにいても最優先で反応します**。全scene共通の反応(ヘルプなど)を置くのに向いています。
- `##line.follow`は「利用者がBotを友だち追加した時」などを表す特別な条件です。Webchatでも、会話の開始時にはこの条件が使われます(Bot管理者が変更している場合があります)。
- 4〜5行目はButtonの選択肢です。C列がボタンのラベル、D列が押したときの行き先です。
- 7行目のように、**B列に`*名前`や`#名前`だけを書くと、そのsceneやlabelへ移動して続きを実行**します。
- `#名前`のlabelには、利用者がその名前を入力しても移動できません。Buttonの行き先やcommandの引数として指定した時だけ移動します。

## 条件の書き方

**条件は「含まれているか」で判定されます。完全一致ではありません。** また、大文字と小文字、全角と半角は区別されません。たとえば条件`こんにちは`は、入力「こんにちは！」や「やあ、こんにちは」にも一致します。

条件は**上から順に調べられ、最初に一致した1か所だけ**が実行されます。短い語の条件(`はい`など)は他の入力にも一致しやすいので、具体的な条件ほど上に書いてください。

| 書き方 | 意味 |
|---|---|
| `ことば` | 入力に「ことば」が含まれていたら一致 |
| `はい&行く` | 両方含まれていたら一致(`&`=かつ) |
| `はい\|うん` | どちらかが含まれていたら一致(`\|`=または)。`( )`でまとめられます |
| `/^はい$/` | 正規表現。`/`で挟みます |
| `/はい/X` | 末尾の`X`を付けると入力全体との完全一致になります |
| `#名前` | labelへの内部action専用の条件 |

どの条件にも一致しない入力には、何も反応しません。

## messageの書き方

- B列に普通の文字列を書くと、そのまま利用者への発言になります。セル内の改行はそのまま表示されます。
- セルの1行目を`話者名:`だけにして2行目から本文を書くと、話者の名前(とBot設定のアイコン)付きで表示されます。
- 1つの条件から返せるmessageは、LINEでは**合計5つまで**です(テキスト、画像、音声、動画、Buttonをそれぞれ1つと数えます。Quick Replyは数えません)。超えるとbuildがエラーになります。テキスト1つはLINEでは300文字までです。

## 主なmessage・command

表示するもの:

| command | 引数 |
|---|---|
| `@image` | 画像URL |
| `@rawimage` | 原寸URL、プレビューURL |
| `@audio` | 音声URL(HTTPS)、再生時間(ミリ秒) |
| `@video` | ポスター画像URL、動画URL、(任意)再生完了後のaction |
| `@button` | 本文、(任意)タイトル、(任意)画像URL。選択肢は右へインデントした行に書く |

物語を進める・覚えるもの:

| command | 使い方 |
|---|---|
| `@set` | `@set $変数名 値` — 変数(flag)を覚える。文章の中に`{$変数名}`と書くと値が埋め込まれる |
| `/if 式` | 式が成り立てば続きの行、`/else`以降はそれ以外、`/end`で合流。`/elif 式`も使える |
| `/seq` | 呼ばれるたびに、`/else`で区切った枝を1つずつ順に実行(最後の枝で止まる)。`/end`で終わる |
| `/loop` | `/seq`と同じで、最後まで行くと最初の枝に戻る |
| `/random` | `/else`で区切った枝からランダムに1つ実行(直前と同じ枝は続けて選ばれない) |
| `@log` | `@log 分類 値` — 分析用の記録を残す。表示はされない |

- commandは`@`と`/`のどちらで書いても同じです(`@if`=`/if`)。日本語名もあります(`/ランダム`など)。
- `/if`の式では変数の比較が書けます。例: `$flag == "on"`、`$count >= 3`、`!$visited`(未設定)、`&&`(かつ)`||`(または)。

`/if`の例:

| A | B | C |
|---|---|---|
| `扉を開ける` | `/if` | `$鍵 == "入手済"` |
| | `扉が開いた。` | |
| | `/else` | |
| | `鍵がかかっている。` | |
| | `/end` | |
| | `あなたは廊下にいる。` | |

## Buttonの選択肢の書き方

インデントした選択肢の行は、セルの数で意味が変わります。

| 書き方(C列、D列、E列) | 押したときの動き |
|---|---|
| `ラベル` | 「ラベル」をそのまま発言する(通常の条件で受ける) |
| `ラベル`、`https://...`(または`tel:`) | リンクを開く |
| `ラベル`、`#名前`または`*名前` | 「ラベル」と発言し、その場所へ移動する |
| `ラベル`、`テキスト` | ボタンは「ラベル」、発言は「テキスト」になる |
| `ラベル`、`表示テキスト`、`#名前` | ボタン・発言・移動先をすべて別々に指定(表示テキストが空なら発言なし) |

`#名前`/`*名前`への移動は「そのボタンが出た場面」の間だけ有効です。物語が先に進んだ後で古いボタンを押しても、何も起こりません。

## Quick Reply(返信の候補)

Bot管理者がQuick Replyプラグインを有効にしていると、記号1つで返信候補を出せます(記号は設定によります。例では`＞`)。

| A | B | C | D |
|---|---|---|---|
| `質問` | `どちらへ行く？` | | |
| | `＞` | `森` | `街=>街へ向かう` |
| | `森を選んだ。` | | |
| | `/else` | | |
| | `街を選んだ。` | | |
| | `/end` | | |
| | `旅がはじまる。` | | |

- C列以降が候補です。`ラベル`はそのまま発言に、`ラベル=>テキスト`は「ボタンはラベル、発言はテキスト」になります。
- 候補を選んだあとは、続きの行から実行されます。候補ごとの分岐は`/else`で区切り、`/end`のあとが共通の続きです(分岐が不要なら候補の行の直後に`/end`)。
- 候補を選ぶまでの間、候補以外の入力は`##please_select_quick_reply`(名前はBot設定によります)という条件に差し替えられます。この条件のブロックを開始sceneに書いておくと、「下の候補から選んでね」のような再提示ができます。

## 定数Sheet

`$`で始まるSheetには、物語のあちこちから使い回す値を書けます。A列に名前、同じ行のB列に型を書き、**次の行から**B列に値を書きます。

| A | B |
|---|---|
| `title` | `value` |
| | `物語の題名` |
| `chapters` | `list` |
| | `第一章` |
| | `第二章` |

- 型は`value`(1つの値)、`list`(一覧)などがあります。`true`／`false`／`null`／数値はその型の値として読み込まれます。
- 定数は文章の中で`{title}`のように埋め込めます。
- 定数Sheetでは`;`で**始まる**行がコメントです(物語のSheetとは規則が違うので注意)。

## Buildと動作確認

1. まずテスト用の環境(テスト用SheetまたはSheet名の`.環境名`)で編集します。
2. 管理画面(`/dashboard/`)の「シナリオ修正の反映」で対象Botをbuildします。
3. エラーが出ていないことを確認します。エラーにはSheet名と行番号が表示されます。
4. 開始、主要な分岐、scene移動、画像・音声、選択肢を、実際の会話でひととおり確認します。
5. 問題がなければ、同じ変更を本番環境へ反映します。

テスト中に自分の会話を最初からやり直すには、Bot管理者が設定した「リセット用の合言葉」を送ります(合言葉は利用者に知られないよう、ここには書きません。管理者に確認してください)。

セルにGoogle Sheetsの式(`=A1&B1`など)を書けるかどうかはBotの設定によります。使える設定でも、`=IMAGE("...")`だけは画像の指定として式のまま扱われます。

## 運用中の更新

公開中もScenarioは更新できます。遊んでいる利用者を途中から継続させたい場合は、次を変えないでください。

- 利用中のsceneやlabelの名前
- 変数(flag)の名前と値の意味
- ButtonやQuick Replyの移動先

また、**Webchatでは変数(flag)の中身が利用者に見えることがあります**。秘密の答え、当選情報、課金に関わる値、他人の情報を変数に入れないでください。

互換性を壊す更新(sceneの大改編など)が必要になったら、Bot管理者に相談してください。利用者に「最初から」やり直してもらう手続きがあります。

## このガイドで扱わないもの

Carousel、Imagemap、Flex、続きを読む(More)、グループ配信、外部サービス連携(`@webhook`、`@postjson`など)、サブルーチン(`@call`)、sceneの共通化(`@include`／`@template`／`@fallback`)は扱っていません。利用するBotでの可否も含めて、Bot管理者に相談してください。Webchatで表示できるmessageの範囲は[Webchatガイド](./webchat.md)にあります。

## Bot管理者向けメモ

作成者向けの本文から外した設定項目です。

- `options.scenario_version`: 既定は3。version 1／2の既存Scenarioを移行する場合は、書式を書き換えるまで値を維持してください。
- `options.reset_keyword`: リセット用の合言葉。**テンプレートの値のまま運用せず、必ず独自の値に変更してください**(送った本人の状態だけが初期化されます)。
- `plugins.webchat.start_action`: Webchatの開始action。既定は`##line.follow`です。
- `plugins.line.quick_reply.command`: Quick Reply短縮記法の記号(例: `＞`)。`please_select_quick_reply_label`が再提示用の条件名です。
- `plugins.google_sheets.evaluate_formula`: Sheets式を評価値として読むかどうか。
- Sheet名の`.環境名`は`XSBOT_DEPLOY_ENV`と比較されます。
- 読み飛ばすSheet(既定は`_`始まり)は`plugins.google_sheets.ignore_sheet`で変更できます。
